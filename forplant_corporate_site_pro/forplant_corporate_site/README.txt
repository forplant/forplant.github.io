FORPLANT 기업 홈페이지 업로드 안내

1. 이 ZIP 파일의 압축을 풉니다.
2. index.html, styles.css, script.js, assets 폴더를 GitHub 저장소 최상위에 업로드합니다.
3. 기존 파일과 이름이 같으면 덮어쓰기(Replace)합니다.
4. CNAME 파일은 삭제하지 마세요.
5. 업로드 후 Commit changes를 누르고 1~5분 뒤 Ctrl+F5로 새로고침합니다.

문의 폼 안내
- GitHub Pages는 서버 기능이 없는 정적 호스팅입니다.
- 현재 문의 폼은 입력 내용을 forplant2024@naver.com으로 보내도록 기본 이메일 프로그램을 실행합니다.
- 웹페이지 안에서 바로 전송되게 하려면 Formspree, EmailJS 같은 외부 서비스 연결이 필요합니다.

지도 안내
- 지도 영역의 버튼을 누르면 입력된 회사 주소로 네이버지도가 새 창에서 열립니다.
