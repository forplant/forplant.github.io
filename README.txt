FORPLANT GitHub Pages 업로드 안내

1. 이 ZIP 파일을 컴퓨터에서 압축 해제합니다.
2. GitHub 저장소에서 기존 CNAME 파일은 그대로 유지합니다.
3. 압축을 푼 폴더 안의 다음 항목을 저장소 최상위에 업로드합니다.
   - index.html
   - styles.css
   - script.js
   - assets 폴더
   - README.txt (선택)
4. Commit changes를 누릅니다.
5. 1~3분 후 사이트에서 Ctrl + F5로 새로고침합니다.
