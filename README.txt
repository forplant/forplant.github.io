FORPLANT 홈페이지 업로드 안내

1. 이 ZIP 파일을 컴퓨터에서 압축 해제합니다.
2. GitHub 저장소에서 CNAME은 그대로 유지합니다.
3. 압축을 푼 폴더 안의 index.html, styles.css, script.js, assets 폴더를 저장소 최상위에 업로드합니다.
4. Commit changes를 누릅니다.
5. 1~3분 후 홈페이지에서 Ctrl+F5를 눌러 확인합니다.

수정 위치
- 회사 문구/정보: index.html
- 디자인: styles.css
- 문의메일 주소: script.js와 index.html의 forplant2024@naver.com
- 로고: assets/forplant-logo.png
- 메인 배경: assets/hero-network-city.png
