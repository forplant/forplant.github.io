FORPLANT 기업형 홈페이지

실행 방법
1. ZIP 파일의 압축을 해제합니다.
2. index.html 파일을 브라우저에서 엽니다.
3. 실제 배포 시 폴더 전체를 웹서버에 업로드합니다.

구성
- index.html : 홈페이지 구조 및 문구
- styles.css : 디자인 및 반응형 스타일
- script.js : 모바일 메뉴 기능
- assets/hero-network-city.png : 생성형 이미지 기반 메인 비주얼

수정 안내
- 이메일 주소: index.html의 contact@forplant.co.kr 변경
- 회사 정보/연락처: footer 또는 문의 섹션에 추가
- 색상: styles.css 상단 :root 변수 수정
